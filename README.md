# Excel for Data Analytics 📊

Welcome to my Excel learning repository! This repository documents my journey of learning Microsoft Excel for Data Analytics through concepts, practical exercises, and datasets.

## 🎯 Learning Objectives
- Understand Excel fundamentals.
- Practice formulas and functions.
- Clean and organize raw datasets.
- Analyze data and generate insights.
- Create reports using Excel tools.

## 📚 Topics Covered

### 1. Excel Basics
- Rows, Columns, Cells, and Worksheets
- Data Types and Formatting
- Sorting and Filtering
- Find and Replace

### 2. Formulas and Functions
- SUM, AVERAGE, MIN, MAX, COUNT
- IF, AND, OR, IFERROR
- SUMIF, SUMIFS
- COUNTIF, COUNTIFS
- VLOOKUP, HLOOKUP, XLOOKUP
- INDEX and MATCH
- Text Functions
- Date and Time Functions

### 3. Data Cleaning
- Remove Duplicates
- Handle Missing Values
- Text to Columns
- TRIM and CLEAN
- Find and Replace

### 4. Data Analysis
- PivotTables
- PivotCharts
- Conditional Formatting
- What-If Analysis
- Database Functions such as DSUM, DCOUNT, and DAVERAGE

### 5. Data Visualization
- Bar Charts
- Column Charts
- Line Charts
- Pie Charts
- Interactive Reports

## 📂 Repository Structure
- `Basics/` — Fundamental concepts and exercises
- `Formulas/` — Formula examples and practice
- `Data-Cleaning/` — Data cleaning exercises
- `Data-Analysis/` — PivotTables and analysis
- `Dashboards/` — Excel reports and dashboards
- `Datasets/` — Practice datasets

## 🛠️ Tools Used
- Microsoft Excel
- CSV datasets
- Git and GitHub

## 🚀 My Goal
To develop strong Excel skills for Data Analytics by practicing with real-world datasets and solving business problems.

I will regularly update this repository as I learn new concepts and complete exercises.
